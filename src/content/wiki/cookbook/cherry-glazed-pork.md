## Ingredients

| Name                     | Quantity  | Necessity |
| ------------------------ | --------- | --------- |
| Pork belly               | 750 g     |           |
| Scallions                | 25 g      |           |
| Ginger                   | 25 g      |           |
| Sichuan peppercorn       | ~10 grain |           |
| Star anise               | 5 g       |           |
| Sand ginger              | 5 g       |           |
| tsaoko                   | 2.5 g     |           |
| Salt                     | 5 g       |           |
| Rock sugar or Cane sugar | 75 g      |           |
| Lard                     | 25 g      |           |
| Soup stock               | 1500 g    | Optional  |
| Cheese cloth bag         | 1 peice   | Optional  |

---
## Cooking Method

| Step | Description                                                                                                                                                                                                                                                        |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1    | Select pork belly with skin. Wash thoroughly and cut into small uniform cubes (~2.5 cm per side).                                                                                                                                                                  |
| 2    | Heat wok over high heat. Add lard and melt.                                                                                                                                                                                                                        |
| 3    | Add sugar and stir-fry until it melts, turn yellow to light brown, and forms bubbles. (Color is the most important sign). Start step 4 **ASAP** before the sugar turn brown to dark-brown (it adds bitterness). You can remove the wok from the heat to avoid this |
| 4    | Add pork cubes and stir-fry until coated in glaze.                                                                                                                                                                                                                 |
| 5    | Pour water (or stock) so that it submerges the pork and rises about 60% **deeper beyond the pork surface**, Add salt.                                                                                                                                              |
| 6    | Bring the mixture to a strong boil and skim off the foam.                                                                                                                                                                                                          |
| 7    | Transfer pork and liquid to a small stew pot for long time slow cook.                                                                                                                                                                                              |
| 8    | Add scallions, ginger, Sichuan pepper, star anise, sand ginger, and tsaoko/cinnamon.                                                                                                                                                                               |
| 9    | Cover with lid. Simmer over low heat, stirring regularly (to prevent pork stick on the bottom). let it cook for 20 min                                                                                                                                             |
|      | remove all spice from the pot, heating them long time will add bitterness                                                                                                                                                                                          |
|      | Slow cook to reduce the broth (to very small amount, only sufficient to sauce the meat surface), until the the skin turn soft enough (can be easily penetrated by fork or chopstick), and the sauce thickened                                                      |

---
## 🔍 Features
- Vivid red glossy pork cubes, evenly shaped and richly glazed.
- Tender, skin-on pork with a sweet-savory aroma and fatty glaze.
- Suitable for banquets or rich rice-paired meals.
---

## 📌 Notes
- **Control sugar heat carefully**: Over-caramelization leads to bitterness.
- Broth adds depth, but plain water is acceptable (can add [Umami Enhancer](/notes/kitchen-modules/umami-enhancers/) to make it closer to broth)
