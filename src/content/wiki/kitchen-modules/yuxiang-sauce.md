## Ingredient
| Name        | quantity | Necessity | Note                                                         |
| ----------- | -------- | --------- | ------------------------------------------------------------ |
| Soy sauce   | 40 g     | Required  |                                                              |
| Sugar       | 20 g     | Required  |                                                              |
| Vinegar     | 15 g     | Required  |                                                              |
| Salt        | 1.5 g    | Required  |                                                              |
| Corn starch | 75 g     | Optional  | For thickening and glaze cling; add as slurry during cooking |
Soy Sauce, Salt, Vinegar should be 8:4:3 by weight 
## Imbalance Diagnosis:
| Problem                             | Fix                                                  |
| ----------------------------------- | ---------------------------------------------------- |
| Soy taste too sharp                 | Add small vinegar first, then sugar if needed        |
| Vinegar taste too sharp             | Add soy to rebalance, then sugar if still too acidic |
| Sauce tastes two-toned / disjointed | Add the weaker of soy or vinegar, in small amounts   |
| Sauce tastes too flat / too sweet   | Add tiny vinegar → unlock aroma; soy for depth       |
## Note
- **Lychee flavor** arises when **soy sauce and vinegar reach a perfect balance** — neither should dominate.
- A good Lychee sauce should feel **smooth, round, slightly acidic, and slightly sweet**, with no jarring edges.

> ❗️Important: **Individual taste sensitivity** varies — some people are more sensitive to sourness, others to soy or sweetness.  Therefore, **you must taste and adjust** to your own preference.
